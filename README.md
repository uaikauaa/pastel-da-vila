# 🥟 Pastel da Vila

> O sabor que une pessoas • Ourinhos - SP

Website institucional e cardápio digital do **Pastel da Vila**, com design moderno, alta performance, foco em pedidos via WhatsApp e responsividade completa para celulares, tablets e computadores.

---

## 🚀 Tecnologias Utilizadas

- **HTML5** (Semântico, Acessível com ARIA, Metadados SEO & Open Graph)
- **CSS3** (Variáveis customizadas, Design System, Efeitos Glassmorphism, Micro-animações e Media Queries)
- **JavaScript Puro (Vanilla JS)** (IntersectionObserver para scroll reveal, controle de menu responsivo, assistente de pedidos via WhatsApp, throttling com `requestAnimationFrame`)
- **Node.js** (Servidor HTTP local de desenvolvimento)

---

## 📋 Funcionalidades

- **Hero Gastronômico:** Destaque em vídeo com pastel crocante frito na hora.
- **Faixa de Diferenciais:** 4 pilares de qualidade com alinhamento fluido.
- **Cardápio Digital:** Seção de pastéis com cálculo de preços e integração direta com WhatsApp.
- **Produtos Secundários:** Sorvetes artesanais, opções de café/pão na chapa e bebidas geladas.
- **História dos Fundadores:** Seção dedicada com foto e valores da pastelaria artesanal.
- **Localização e Horários:** Informações claras com atalho para o Google Maps e horários de atendimento.
- **Rodapé Minimalista:** Identidade da marca, endereço, link para o Instagram oficial e botão de pedido.
- **Botão Flutuante:** Atalho rápido para atendimento e pedidos no WhatsApp.

## 💻 Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/uaikauaa/pastel-da-vila.git
```

2. Acesse a pasta do projeto:
```bash
cd pastel-da-vila
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
# ou
node server.js
```

4. Abra no navegador:
```
http://localhost:3000
```
